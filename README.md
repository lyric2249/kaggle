# kaggle

Kaggle 실습/분석 노트북을 모아두는 개인 학습용 저장소입니다.

## 저장소 구성

- `/2025`
  - 2025년 Kaggle 관련 노트북
  - `20251228.ipynb`
  - `20251228_Mercor.ipynb`
  - `20260103_santa.ipynb` (현재 빈 노트북)

- `/BDA`
  - 데이터 분석 연습 노트북
  - `000.ipynb`
  - `000_EDA.ipynb`

- `/ADP`
  - Git submodule로 연결된 별도 저장소
  - `.gitmodules` 기준: `https://github.com/lyric2249/ADP`

## 사용 방법

1. 저장소 클론
2. (필요 시) 서브모듈 초기화
   - `git submodule update --init --recursive`
3. Jupyter Notebook 또는 VS Code에서 `.ipynb` 파일 열어 실습

## 참고

- 일부 노트북은 Kaggle 기본 Python 환경 템플릿으로 시작합니다.
- 진행 중인 노트북(빈 파일 포함)이 있을 수 있습니다.
